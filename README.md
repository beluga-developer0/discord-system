# 🛡️ BelugaBot Blacklist System (v4.5)

Полностью асинхронная, стабильная и автономная система управления Черным Списком (ЧС) и текстовыми апелляциями для Discord-ботов, написанная на Python с использованием библиотеки `discord.py`.

---

## ✨ Основные особенности

* **⚙️ Полная асинхронность**: Оптимизированное ядро на базе `app_commands.Group` (слэш-команды нового поколения).
* **📄 Умная пагинация**: Автоматическое разделение списков ЧС и обжалований на страницы с кнопками «Назад» и «Вперед» для обхода жестких лимитов Discord (25 полей в Embed).
* **✉️ Личные апелляции**: Забаненные пользователи могут подать обжалование, просто написав боту в ЛС. Слэш-команды для этого не требуются.
* **🔗 Автозахват медиа**: Бот автоматически перехватывает прикрепленные к апелляции скриншоты/доказательства и сохраняет их в базу данных.
* **🔍 Гибридный кэш имен**: Запрос имен нарушителей идет через оперативную память, что предотвращает зависание команд и блокировки от Discord API (Rate Limit).
* **⏱️ UTC-таймзоны**: Автоматическое снятие просроченных банов работает корректно на любых зарубежных хостингах.
* **💾 Авторазвертывание**: Бот сам создаст пустые JSON-файлы базы данных при первом запуске.

## 🚀 Инструкция по установке и запуску

### 1. Требования
Для работы бота необходим **Python 3.8 или выше** и установленная библиотека `discord.py`.

### 2. Установка зависимостей
Откройте терминал/консоль в папке с ботом и выполните команду:
```bash
pip install discord.py
```

### 3. Настройка Intents в Discord Developer Portal
Для корректной работы бота необходимо зайти на [Discord Developer Portal](https://discord.com), выбрать вашего бота, перейти во вкладку **Bot** и в блоке **Privileged Gateway Intents** включить галочку:
* `MESSAGE CONTENT INTENT` (Обязательно для обработки апелляций в ЛС).

### 4. Первый запуск
Запустите файл бота через консоль:
```bash
python bot.py
```
При первом запуске бот попросит вас ввести токен. Введите его в консоль. Бот автоматически сохранит его в файл `token.json` и при последующих запусках запрашивать не будет.

## 📋 Список команд бота

### 👑 Команды Владельца бота (Owner)

| Команда | Описание | Примечание |
| :--- | :--- | :--- |
| `/set-beluga [user_id]` | Установить ID главного разработчика (Beluga Develop) | Доступно только создателю бота |

### 🛠️ Команды Разработчика (Beluga Develop)

| Команда | Описание | Примечание |
| :--- | :--- | :--- |
| `/чс выдать [пользователь] [время] [причина]` | Выдать ЧС пользователю по его ID или упоминанию | Время задается в формате: `1d` (день), `12h` (часов), `30m` (минут), `permanent` (навсегда) |
| `/чс снять [пользователь]` | Досрочно снять ЧС с пользователя | Отправляет уведомление пользователю в ЛС |
| `/чс список` | Просмотреть интерактивный список всех активных ЧС | Использует страницы (пагинацию) |
| `/модер добавить [пользователь]` | Назначить пользователя модератором системы ЧС | Позволяет проверять инфо и смотреть списки |
| `/модер удалить [пользователь]` | Лишить пользователя прав модератора системы ЧС | — |
| `/настройки уведомления [вкл/выкл]` | Включить или выключить отправку уведомлений в ЛС нарушителям | Сохраняется в настройки |

### 🛡️ Команды Модераторов системы ЧС

| Команда | Описание | Примечание |
| :--- | :--- | :--- |
| `/чс инфо [пользователь]` | Проверить статус пользователя, его историю и количество банов | Доступно Beluga + Модераторам |
| `/обжаловать список` | Открыть интерактивный список заявок на обжалование | Просмотр скриншотов кнопками |
| `/обжаловать рассмотреть [номер] [решение]` | Одобрить или отклонить заявку нарушителя по её номеру | При одобрении ЧС снимается автоматически |
| `/статистика общая` | Посмотреть общую статистику выданных, снятых банов и заявок | — |

### 👤 Публичные команды (Доступны всем)

| Команда | Описание | Примечание |
| :--- | :--- | :--- |
| `/myid` | Узнать свой Discord ID и проверить, находитесь ли вы в ЧС | Работает везде |
| `/пинг` | Проверить текущую задержку бота (latency) | Ответ в миллисекундах |

## 📝 Как работает система обжалования для игроков

1. Когда пользователь находится в ЧС, он может открыть личные сообщения с ботом и написать любой текст (свою причину, почему бан должен быть снят).
2. Пользователь может прикрепить к сообщению **один файл или скриншот** — бот автоматически прикрепит его как доказательство.
3. Бот мгновенно пересылает заявку в личные сообщения всем зарегистрированным модераторам.
4. Модераторы могут использовать команду `/обжаловать список` для пролистывания и изучения заявок, а командой `/обжаловать рассмотреть` вынести вердикт.
